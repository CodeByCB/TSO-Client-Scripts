# TSO Client Scripts

Unofficial quality-of-life scripts for the community-maintained *The Settlers Online* desktop client.

Copyright © 2026 CodeByCB (China Blue)

## Available scripts

| Script | Description | Documentation |
| --- | --- | --- |
| `user_cb_ChatReconnect.js` | Attempts to restore a lost in-game chat connection without restarting the client. | [Chat Reconnect](docs/ChatReconnect.md) |

More scripts may be added to this repository in the future.

## General installation

1. Download the required `.js` file from this repository.
2. Copy it into the client's `userscripts` folder.
3. Keep the filename unchanged.
4. Restart the client, or use the client's normal script-reload method if one is available.

Instructions and limitations specific to each script are kept in that script's linked documentation.
